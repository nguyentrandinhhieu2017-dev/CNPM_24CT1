Mở trang Đăng ký

Mở trang Quên mật khẩu
Hướng dẫn dùng với Figma:
  1. Mở Figma và cài đặt plugin "html.to.design" (hoặc tiện ích Chrome tương ứng).
  2. Chọn tab "Direct HTML" hoặc copy nội dung mã nguồn file .html dán vào plugin.
  3. Hoặc kéo thả file HTML trực tiếp vào plugin để tự động sinh Frame giao diện với Auto-layout và Fonts đầy đủ.
