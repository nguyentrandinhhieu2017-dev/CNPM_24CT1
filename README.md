# LiveTech Auction System

## System Architecture
- **Frontend**: Thymeleaf, HTML, CSS, JavaScript
- **Backend Framework**: Java Spring Boot
- **Database**: **MySQL Database** (livetech_auction_db)
- **External Services**: Gemini API (Chatbot), QR Payment (MBBank)

## Database Configuration
The system connects strictly to a central **MySQL Database** to manage Users, Products, Bids, and Orders. Do not split into multiple databases.
